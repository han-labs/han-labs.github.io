# Huynh Gia Han Portfolio

Personal portfolio for Software Developer Intern applications.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

This repo includes a GitHub Pages workflow in `.github/workflows/deploy.yml`.

In GitHub:
1. Go to Settings → Pages.
2. Set Source to GitHub Actions.
3. Push to `main`.
