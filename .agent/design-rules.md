# Design Rules

Use the free TypeUI Neobrutalism Design System as visual inspiration if reference files/screenshots are provided in `references/typeui`.

## Style
- Thick black borders
- Hard offset shadows
- High contrast
- Bold typography
- Geometric cards
- Playful but professional
- Strong section headings
- Clear hierarchy

## Avoid
- Glassmorphism
- Too many gradients
- Excessive animations
- Overly soft shadows
- Long paragraphs

## Layout Flow
Navbar → Hero → About → Skills → What I Can Contribute → Featured Projects → Achievements Timeline → Beyond the Code → Certificates → Latest Writing → Contact → Footer

Projects must appear before achievements and certificates.
